# Kishan Hotel — Immersive Website

A responsive, editorial hotel website inspired by the immersive storytelling and motion language of ERA Residence. Built with React, TypeScript, Vite, and GSAP/ScrollTrigger.

## Features
- Full-screen photographic hero and editorial story sections
- GSAP scroll reveals and scrubbed image parallax
- Desktop pinned horizontal room gallery with mobile swipe fallback
- Day/night theme toggle
- Responsive navigation and room gallery controls
- Reduced-motion support and semantic navigation

## Run locally

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Content to confirm before launch
Replace placeholder room descriptions, hotel address, booking contact, and stock imagery with Kishan Hotel's verified information and licensed photography. The current design is an original interpretation, not a pixel-for-pixel copy of ERA Residence.
